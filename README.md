# Demo-pet 🐾

An interactive Tamagotchi-style web application inspired by my favorite TV show. This project demonstrates core JavaScript concepts, state management, and real-time asynchronous data updates.

## 🚀 Key Features

* **Real-time State Tracking:** Implemented dynamic stats (hunger, boredom, energy) that deplete over time using asynchronous JavaScript timers.
* **Interactive UI:** Developed responsive game controls allowing users to feed, play with, and put the pet to sleep, instantly rendering state changes in the DOM.
* **Game Loop & Logic:** Designed a conditional game loop to monitor pet stats, trigger critical warnings, and handle "game over" scenarios.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom animations and layouts)
* **Core Logic:** Vanilla JavaScript (ES6+, Asynchronous Programming, DOM Manipulation, Event Handling)

## 🧠 What I Learned

* Managing and updating application state in real-time using `setInterval` and `setTimeout`.
* Working deeply with DOM selectors, event listeners, and dynamic class toggles for visual effects.
* Debugging asynchronous code and optimizing logic flows.
